## 4. Music — Nyan Cat theme material

The historical game contains **two different musical tracks associated with the Nyan Cat theme**:

1. a version of the original theme commonly associated with the Nyan Cat meme;
2. a separate **piano arrangement used on the title / welcome screen**, whose arranger, performer, recording source, and licensing terms are currently unknown.

The underlying composition commonly associated with the meme is **“Nyanyanyanyanyanyanya!”**, originally composed by **daniwell / daniwellP**. The version widely associated with the viral Nyan Cat video is based on a later Momone Momo / UTAU cover.

The exact provenance and redistribution rights of the specific historical audio files included with this project have not yet been verified conclusively. This applies especially to the piano arrangement, whose authorship is currently unknown.

Accordingly, **both music files are expressly excluded from the MIT License and the CC BY-NC-SA 4.0 license granted by this repository**.
